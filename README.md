## <img src="https://cdn3.emoji.gg/emojis/85336-typing.gif" width="36px" align="absmiddle"> CustomTyping

**CustomTyping** is a lightweight CSS customization that replaces Fluxer's default typing indicator with a personalized message.

Instead of the standard *"is typing..."* indicator, you can display your own custom text.

### Features

- 📝 Custom typing messages.
- 🎨 Preserves existing username colors, including role colors.
- 👥 Supports multiple typing users.
- 🌙 Adapts to Fluxer's current theme through CSS variables.
- ⚡ Lightweight CSS-only customization.
- 🔧 Easy to personalize and modify.

### Preview

Default:
```text
Alice is typing...
```

With CustomTyping:
```text
Alice is cooking...
```

The message can easily be changed to anything you like.

### Installation

1. Download the `CustomTyping.css` file.
2. Open Fluxer.app.
3. Open your custom CSS editor or the tool you use to inject custom styles.
4. Paste the contents of the CSS file or import it.
5. Save your changes and refresh Fluxer if necessary.

### Customization

You can change the typing message by editing the `content` property in the CSS file.

For example:

```css
content: " is cooking...";
```

Replace it with your preferred message:

```css
content: " is plotting something...";
```

Other ideas:

- `is touching grass...`
- `is losing braincells...`
- `is being suspicious...`
- `is probably AFK...`
- `is in love...`
